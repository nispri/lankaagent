**Date:** [DATE]

---

## 1. Purpose
This LOI establishes a **zero-cost, 30-day pilot** of the LankaAgent AI Travel Concierge widget on the Pilot Partner's website. The goal is to validate lead capture, itinerary generation, and wellness upsell conversion in a live operator environment.

---

## 2. Pilot Scope

| Item | Details |
|------|---------|
| **Duration** | 30 calendar days from widget go-live |
| **Widget Variant** | Embedded iframe (full-screen chat) or floating toggle |
| **Branding** | Pilot Partner's colors, logo, welcome message, languages |
| **Languages** | English + up to 6 additional (RU, DE, FR, ZH, SI, TA) |
| **Features Included** | 24/7 chat, lead capture, AI itinerary generation, wellness protocol upsell |
| **Data Ownership** | All leads, conversations, itineraries belong to Pilot Partner |
| **Cost** | $0 for pilot period |

---

## 3. Responsibilities

### LankaAgent (Provider)
- [ ] Provision tenant with agreed branding
- [ ] Provide iframe embed code + integration support (15-min screen share if needed)
- [ ] Maintain 99.5% uptime during pilot (ngrok tunnel + API)
- [ ] Weekly 15-min check-in call
- [ ] Deliver pilot report at close (conversations, leads, itineraries, conversion)

### Pilot Partner (Operator)
- [ ] Embed widget on live website (homepage + tour pages)
- [ ] Route at least 50% of web chat traffic to widget during pilot
- [ ] Provide feedback on response quality, missing knowledge, UX
- [ ] Designate 1 point of contact for weekly check-ins
- [ ] Allow anonymized pilot metrics in LankaAgent marketing (opt-out available)

---

## 4. Data & Privacy
- All data stored in **PostgreSQL with Row Level Security** — Pilot Partner's data is cryptographically isolated
- No data shared with other tenants or third parties
- Pilot Partner can request full data export at any time
- GDPR/PDPA compliant — data processed in Sri Lanka / EU regions

---

## 5. Pilot Success Criteria (Non-Binding)

| Metric | Target |
|--------|--------|
| Conversations initiated | ≥ 20 |
| Qualified leads captured | ≥ 5 |
| Itineraries generated | ≥ 3 |
| Wellness upsell triggers | ≥ 2 |
| Operator satisfaction (NPS) | ≥ 8/10 |
